# Postman Collection

Import `MovieLibrary.postman_collection.json` into Postman.

1. Start the app locally with `npm run dev`.
2. Keep `baseUrl` as `http://localhost:3000`, or change it to your deployed Vercel URL.
3. Run `Create workspace and save ID` first. It saves `workspaceId` automatically.
4. Run `Create movie and save ID`. It saves `movieId` automatically.
5. Run the remaining requests in order to practice GET, PUT, PATCH, DELETE, and 404 verification.

The collection uses current `pm.*` scripting APIs and stores IDs in collection variables.
